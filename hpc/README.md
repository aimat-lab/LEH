# Cluster scripts

Slurm scripts used for the paper: TURBOMOLE labelling and reference dynamics on bwUniCluster (`aimd_*`, `eigvec_escf.sh`,
`bwuni_*`), training and evaluation on HoreKa (`hk_*`), and training on a KIT GPU cluster (`kcist_train.sh`). Workspace
paths are replaced by `/path/to/workspace` and accounts by `<account>`; adapt partitions, accounts, and paths to your
cluster. TURBOMOLE is commercial software and must be installed separately (`TURBODIR`).
